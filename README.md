## 🗺 学科拓扑结构 (Discipline Structure)

本仓库涵盖西方哲学史全部 11 大主干阶段，每个阶段细分为原子知识容器：

- `0_myth_and_language/`: 史前神话思维、语言的起源与本原（Archē）问题
- `A_ancient_greece/`: 米利都学派、毕达哥拉斯、赫拉克利特、巴门尼德、智者学派与苏格拉底
- `B_hellenistic_rome/`: 柏拉图理念论、亚里士多德实体学说、斯多葛主义与伊壁鸠鲁
- `C_medieval_patristic/`: 教父哲学、唯名论与实在论之争、托马斯·阿奎那经院哲学
- `D_early_modern/`: 笛卡尔我思、斯宾诺莎实体、莱布尼茨单子论、经验主义（洛克/巴克莱/休谟）
- `E_german_idealism/`: 康德三大批判、费希特、谢林、黑格尔绝对精神
- `F_late_19th/`: 叔本华意志哲学、尼采权力意志、克尔凯郭尔存在先于本质
- `G_marx/`: 历史唯物主义、异化劳动与商品拜物教批判
- `H_phenomenology/`: 胡塞尔现象学、海德格尔存在与时间、萨特存在主义
- `I_analytic_logic/`: 弗雷格逻辑学、罗素摹状词、维特根斯坦《逻辑哲学论》与《哲学研究》
- `J_postmodern/`: 福柯话语权力、德里达解构主义、德勒兹千高原
